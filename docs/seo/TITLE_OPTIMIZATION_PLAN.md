## 1. Core Principles & Audit Findings

### Audit Summary:
1. **Root Layout Title Flaw**: Current root title is `"PerfectProperty — Find the opportunity that changed"` (51 chars). While character count is within bounds, it contains **zero search intent keywords**. An investor looking for sheriff sales or foreclosures will never type "find the opportunity that changed."
2. **Listings Page Truncation**: Current `/listings` title is `"Search Foreclosure and Auction Properties | PerfectProperty"` (58 characters). On mobile Google SERPs (cut off at ~55 characters), the brand name and end words are truncated. "Search" is an empty filler verb.
