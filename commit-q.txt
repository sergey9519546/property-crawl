test(discovery): cover parseBbox pure helper in 9 unit tests

Direct unit coverage for the parseBbox query-param parser exported
from server/discovery/query.js. It is the geo filter guard on every
discovery query — silent drift would either accept malformed input
or reject legitimate queries on the wrong shape. (parseBool and
parseDate are private to the module — only parseBbox is exported.)

Pins:
- null / undefined / empty input returns null
- parses a valid west,south,east,north bbox
- rejects wrong number of values
- rejects non-finite numbers (NaN, "not")
- rejects lat outside [-90, 90] for both south and north
- rejects lng outside [-180, 180] for both west and east
- rejects south >= north (inverted latitude range)
- rejects west === east (zero-width longitude range)
- accepts the documented boundary values (lng=-180, lat=90, lat=-90)

Wired into test:canonical so CI exercises the new file.
