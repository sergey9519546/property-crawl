test(sources): cover observations compareSnapshots in 15 unit tests

Direct unit coverage for compareSnapshots exported from
server/sources/observations.js. It is the function the discovery
evidence pipeline uses to decide which field-level changes become
"signals" surfaced to operators. Silent drift in either direction
would either suppress legitimate publisher updates or invent
changes that don't exist.

Pins:
- missing previous or same-or-earlier observedAt returns empty array
  (newly populated fields don't demonstrate a change)
- openingBid: bid_reduced vs bid_changed numeric comparison
- saleDate: sale_date_changed
- status: returned_to_market for the documented transitions;
  status_changed otherwise
- deposit: terms_changed
- address: address_changed
- identical values skip the field (no false positives)
- missing field on one side is skipped (no fabrication)
- multiple simultaneous field changes all surface
- mixed-case status vocabulary is tolerated

Wired into test:sources so CI exercises the new file.
