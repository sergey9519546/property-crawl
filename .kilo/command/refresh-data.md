# /refresh-data

Regenerate the static data registry.

- `npm run refresh-data` — offline rebuild from cached scraper output.
- `npm run refresh-data:real` — live network scrape + rebuild.

`data.js` is AUTO-GENERATED by `scripts/build-data.js` — do not hand-edit. Follow with `node scripts/gen-context.js` so `CONTEXT.md` reflects the new taxonomy. `test/sync.test.js` and `test/context.test.js` fail CI on drift.
