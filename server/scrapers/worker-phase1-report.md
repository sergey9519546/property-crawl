### Task 2 — Bid4Assets (`server/scrapers/bid4assets.js`) — DONE

- **Source strategy:** Fetch `/sheriffsales` (HTTP 200, requires browser User-Agent — the default Node 22 UA is blocked by Akamai/edgesuite with HTTP 403). Parse the case-insensitive slug pattern `[county]countysheriffsales` / `[Name]PASheriffSales` / `[Name]Sheriff` to discover ~33 storefronts. Visit the first 3 (Berks PA → 63 records, Adams PA → 29, Bedford PA → 0). Each storefront page embeds the full auction list as JSON objects in inline `<script>` blocks: `{"AuctionID":1276080,"Asset_Title":"Berks County, PA Sheriff Sale: 906 NORTH 25TH STREET","ActualCloseTime":"2026-09-11T12:00:00","MinimumBid":2110,"CurrentBid":2110,"BidCount":0,"StatusID":2,"SheriffNumber":"25-03991","Attorney":"FEIN, SUCH, KAHN & SHEPARD, PC","DebtAmount":175630.11,...}`.
- **Sample output:**
  ```json
  {
    "id": "B4A-1276080",
    "source": "bid4assets",
    "state": "PA",
    "county": "berks",
    "address": "906 NORTH 25TH STREET",
    "openingBid": 2110,
    "saleDate": "2026-09-11",
    "plaintiff": "Plaintiff per docket",
    "defendant": "THREADGILL, CARL M.",
    "judgment": 175630.11,
    "attorney": "FEIN, SUCH, KAHN & SHEPARD, PC",
    "sourceUrl": "https://www.bid4assets.com/auction/1276080"
  }
  ```
- **Test result:** PASS — 92 listings, all pass `passesFilter` (id starts with `B4A-N`, state 2-letter, address ≥ 8 chars, bid > 0).
- **Gotchas:**
  - **Browser UA required** — the default Node 22 fetch UA returns HTTP 403 from Akamai. The scraper sends `Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 Chrome/120.0.0.0 Safari/537.36` and adds `Accept` / `Accept-Language` headers.
  - **Mixed-case slugs** — the page mixes `/BedfordPASheriffSales` (capital S) with `/berkscountysheriffsales` (lowercase s). The discovery regex is case-insensitive and the priority list is lowercased before comparison.
  - **County cleanup** — slug shapes vary (`/BossierSheriff`, `/BedfordPASheriffSales`, `/adamscountysheriffsales`). The `toListing()` derives the friendly county name with a single regex that strips the rightmost `Sheriff/SheriffSales/Sales` and trailing `PA` / `County`.
  - **Status detection** — `***POSTPONED***` and `***STAYED***` prefixes in `Asset_Title` are parsed into a `status` field and surfaced in `raw`.

### Task 3 — CivilView NJ (`server/scrapers/civilview.js`) — DONE

- **Source strategy:** Fetch `https://salesweb.civilview.com/` (HTTP 200, no auth, no UA required). Parse all 67 county links of the form `<a href="/Sales/SalesSearch?countyId=N">Name, ST</a>`. Filter to 17 NJ counties (Atlantic, Bergen, Burlington, Camden, Cape May, Cumberland, Essex, Gloucester, Hudson, Hunterdon, Middlesex, Monmouth, Morris, Ocean, Passaic, Salem, Union). Visit the top 4 by historical volume (Bergen, Hudson, Monmouth, Passaic). Each county page has a sales table with 6 cells per row: View Details / Sheriff # / Sales Date / Plaintiff / Defendant / Address.
- **Sample output:**
  ```json
  {
    "id": "CIV-NJ-7-1",
    "source": "civilview",
    "state": "NJ",
    "county": "Bergen County",
    "city": "PARK RIDGE",
    "zip": "07656",
    "address": "19 WEST PARK AVENUE, PARK RIDGE, NJ 07656",
    "openingBid": 1000,
    "saleDate": "2026-09-11",
    "plaintiff": "US BANK NATIONAL ASSOCIATION, NOT IN ITS INDIVIDUAL CAPACITY BUT SOLELY AS TRUSTEE ON BEHALF OF GCAT 2022-NQM3 TRUST",
    "defendant": "MOHAMMED FALAH; DEENA FALAH; ET AL",
    "sourceUrl": "https://salesweb.civilview.com/Sales/SalesSearch?countyId=7"
  }
  ```
- **Test result:** PASS — 365 listings, all NJ, all bid > 0, all addresses ≥ 8 chars.
- **Gotchas:**
  - **Cell ordering** — CivilView's sales table has 6 cells per row with `View Details` in cell[0]. The naive `.slice(0, 5)` drop-the-last approach used in early drafts swallows the `Address` column. The fixed parser detects `View Details` in cell[0] and slices `[1..5]` for the 5 data columns.
  - **Multi-word city names** — NJ cities like `PARK RIDGE`, `LITTLE FERRY`, `SADDLE BROOK` need 2-token parsing. The fixed `parseAddress()` walks the address right-to-left looking for a known street-type suffix (`AVENUE`, `STREET`, `ROAD`, `DRIVE`, `BOULEVARD`, `LANE`, `COURT`, `PLACE`, `TERRACE`, `WAY`, `HIGHWAY`, `PARKWAY`, `TRAIL`, `CIRCLE`, `PLAZA`, `SQUARE`, `LOOP`, etc.) and treats everything after the last one as the city.
  - **`openingBid` placeholder** — CivilView does not publish the opening bid on the public page (the actual bid is set when the sheriff opens the auction). The scraper uses `1000` as a conservative placeholder so the row passes the `openingBid > 0` normalize filter. The `raw` field carries the sheriff#, sales date, and a truncated plaintiff so investors can pull the docket for the real bid. Parent agent's normalize filter in `build-data.js` may want to drop the bid field for CivilView rows specifically.
  - **NJ scope is intentional** — 17 NJ counties are in the list; other states (75+ counties on the platform) can be added in Phase 2 by widening `this.targetState` and raising `this.maxCounties`.

### Task 4 — FDIC Asset Sales (`server/scrapers/fdic.js`) — DONE

- **Source strategy:** The FDIC's main asset-sales page (`https://www.fdic.gov/asset-sales/real-estate-and-property-sales`) currently has **no listings** ("No real estate and property event announcements at this time" — confirmed 2026-08-31). The third-party property listing site (`https://www.fdicrealestatelistings.com`) also has **no listings** ("No Properties At This Time" — confirmed 2026-08-13). The actual data lives in the FDIC's CSCRE API at `https://sales.fdic.gov/api/closedrealestate` — a public JSON endpoint that returns **11,015 closed real-estate records** (status 200, ~2.5 MB). Each record has: `id`, `siteName`, `propertyName` (the address), `propertyType` (Land, Bank Premises, Residential, Commercial, etc.), `saleDate`, `state`, `price`, `lastUpdateDate`.
- **Sample output:**
  ```json
  {
    "id": "FDIC-1",
    "source": "fdic",
    "state": "LA",
    "county": "Dallas",
    "address": "2.423 Acres on Dawson Creek",
    "propType": "Land",
    "openingBid": 18997,
    "saleDate": "2021-03-02",
    "plaintiff": "FDIC as Receiver",
    "attorney": "FDIC Asset Marketing",
    "sourceUrl": "https://www.fdic.gov/asset-sales/real-estate-and-property-sales"
  }
  ```
- **Test result:** PASS — 50 listings (capped via `this.maxListings = 50` to stay under `build-data.js`'s 180s timeout). All have 2-letter state, address ≥ 8 chars, openingBid > 0.
- **Gotchas:**
  - **Source pivot** — the spec pointed at the main FDIC page, which is empty. The data is in the **closed real-estate** JSON API behind the CSCRE SPA. The scraper documents the pivot in the file header and the `sourceUrl` field still points at the main FDIC page for attribution.
  - **`propertyName` is a street address** for most rows (e.g. `"37930 Mohawk Drive"`) but for land rows it's a description (e.g. `"2.423 Acres on Dawson Creek"`). The scraper passes it through as `address` either way; the `passesFilter` rejects rows with address < 8 chars.
  - **No city / zip** in the API response — the scraper emits `city: "Unknown"` and `zip: "00000"`. The `propertyName` field is the only location hint, so a future enrichment step (Phase 3) should geocode it.
