# Memory — Facts (invariants, decisions, ground truth)

> Persistent global facts. Every entry cites its source file. No hallucinated facts.
> Updated by the agent after significant changes; read at session start.

## Architecture

- **Three layers**: v0 static PWA (`index.html`/`app.js`), v1 Node `http` API (`server/`), v2 Next.js 16 App Router (`src/`).
  - Source: `CONTEXT.md`, `AGENTS.md`
- **No database required to boot**: `server/db/client.js` falls back to in-memory provider seeded from `data.js` when `DATABASE_URL` is unset.
  - Source: `server/db/client.js`, `AGENTS.md`
- **API port**: `server/server.js` listens on port 3000; Next dev on 3001. Base44 compose maps UI to 3000 and proxies API.
  - Source: `AGENTS.md`, `docker-compose.base44.yml`

## Invariants (do not violate)

- Every dynamic/AI/user string renders through `esc()` / `mdToHtml()` (XSS invariant).
  - Source: `CONTEXT.md`, `app.js`
- `SCORE_BANDS` is the single source of truth for Deal Score color/label/alpha.
  - Source: `CONTEXT.md`, `app.js`
- Listing contract is camelCase (`dealScore`, `openingBid`, `propType`); Postgres stores snake_case and `server/db/client.js` aliases back.
  - Source: `CONTEXT.md`, `server/db/client.js`
- All scraper network calls must be wrapped in `ScraperCircuitBreaker`.
  - Source: `.agents/skills/property-scraper-engineering/SKILL.md`, `server/scrapers/circuit-breaker.js`
- Never overwrite existing records with zero-byte or 403 error payloads.
  - Source: `.agents/skills/property-scraper-engineering/SKILL.md`
